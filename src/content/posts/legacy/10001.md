Hexo+Butterfly主题博客搭建01 ——— 个人博客搭建的基础环境配置工作

# Node.js的配置

[nodejs的官网](https://nodejs.org/en/download)

选择适合自己系统的下载即可，大部分人应该是Windows Installer (.msi) 64位，选择msi位安装程序，mac和linux用户选择适合自己的版本即可。

安装是一路默认选项即可，**注意安装的路径可以根据自己的需求，一定要记住安装在哪里了**

安装完成之后可以在cmd中测试是否安装成功

```text
node -v
```

```text
npm -v
```

安装后重新打开终端，分别执行上面的 `node -v` 与 `npm -v`。两条命令都能返回版本号，才说明当前终端可以找到对应程序；具体版本以本机实际输出为准。如果提示命令无法识别，先确认安装过程已完成、终端已重开，再检查安装目录是否加入 `PATH`。若机器上装过多个版本，还应检查命令实际解析到的路径，避免后续安装 Hexo 时使用了另一套环境。

# github的配置

在github新建一个仓库

> 名称为 **你的名称.github.io**

个人主页仓库的配置要点：

仓库的关键配置是所有者与名称匹配：个人主页仓库命名为 `<用户名>.github.io`，其中用户名使用实际的 GitHub 账号名，而不是昵称。登录后从仓库创建入口填写名称，创建后核对仓库地址和所有者。随后在仓库设置中找到 Pages 的发布配置，按采用的部署方式选择分支发布或工作流发布；建好仓库本身并不代表站点已经发布，还需要后续生成并部署博客内容。

# 博客的初始化

## 安装Hexo

所有必备的应用程序安装完成后，即可使用`npm`安装`Hexo`。不要觉得安装这个框架有多复杂，只需要一条命令就可以了。`npm`是安装工具，`install`表示安装，`-g`表示全局安装，`hexo-cli`表示安装的是hexo框架。

在 git 命令行下输入下述的命令，**若无法安装可能是因为权限不够，可以以管理员权限运行 gitbash**

```text
npm install -g hexo-cli
```

## 初始化博客

安装完框架之后新建一个存放博客的文件夹Blog，这里在D盘新建了一个Blog文件夹，在该文件夹下右键Git Bash Here并输入`hexo init`命令初始化这个文件夹。注意新建 Blog 文件夹和初始化这个文件夹只需要下面这条命令就可以了。

## 启动和配置博客

```text
hexo clean  # 清除缓存
hexo g      # 生成静态网页
hexo d      # 部署到Github
hexo s 		# 是 hexo server 的缩写，启动本地服务器，用于预览主题。默认地址： http://localhost:4000/
```

此时输入 `hexo clean` `hexo d` `hexo h` `hexo s` 命令即可初步查看自己的 Blog 页面  
在浏览器输入 [http://localhost:4000/](http://localhost:4000/) 即可访问  
顺利的话，在浏览器输入：`用户名.github.io` 即可初步访问自己的博客
